03 · Case study

Tourism App Design System

A reusable interface foundation for a tourism product in Southern Brazil, designed to improve consistency, accessibility and scalability across new screens.

ContextConfidential project · Digital product · 2026
Areas
Design SystemUI DesignComponentsAccessibilityScalability

Overview

What the project is solving

The project required a system that could support product growth without rebuilding visual and interaction decisions screen by screen. The work covers visual foundations, reusable components, variants, states and interface patterns.

My contribution

Where I contribute

My contribution focused on structuring the design system foundations and reusable UI logic so future screens can be created with greater consistency and less duplicated decision-making.

Design focus

The parts of the work that matter most

01

System foundations

Defining the visual foundations and recurring interface rules that support the product.

02

Reusable components

Structuring components, variants and states to support multiple interface contexts.

03

Consistency & accessibility

Using consistency, accessibility and scalability as criteria for the system rather than treating them as final polish.

Scope note

This project is confidential. The case therefore explains the system logic and design responsibilities without publishing proprietary screens or client-sensitive material.
